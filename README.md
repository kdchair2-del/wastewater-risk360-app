# 하폐수처리장 360° 위험성평가

## 실행 방법

1. `index.html`과 사진 파일을 같은 폴더에 둡니다.
2. `index.html`을 더블클릭해 Chrome 또는 Edge에서 엽니다.
3. 기본 사진은 `하폐수처리시설_집수조_파노라마(실습용도식).jpg`입니다. 다른 사진은 **사진 바꾸기**에서 선택할 수 있습니다.

설치나 서버가 필요하지 않습니다. 입력 내용은 현재 브라우저의 로컬 저장 공간에 자동 보관됩니다. 브라우저 데이터를 지우거나 다른 브라우저·컴퓨터에서 열면 자동 저장 내용이 보이지 않을 수 있으니 **작업 저장**으로 JSON 파일도 보관하세요.

## 현장 둘러보기

- 사진 가운데에서 드래그하거나 좌우 화살표 키로 이동합니다. 가장자리 마우스 이동과 자동 회전은 아래 토글에서 끌 수 있습니다.
- `＋ 핀 추가`를 누른 다음 사진에서 위험 위치를 누르면 핀이 생깁니다.
- 핀을 선택하면 오른쪽 **선택한 핀**에서 유형, 위험요인, 점수와 대책을 입력·수정할 수 있습니다.
- 핀 위치는 사진을 기준으로 저장됩니다. 핀을 사진이나 미니맵에서 끌거나 x·y 값을 입력해 조정할 수 있습니다. 방향키로 미세 조정하고 Shift+방향키로 크게 움직입니다.
- **핀 모두 제거**는 확인 후 핀 전체를 삭제합니다. 지운 핀은 되돌릴 수 없으므로 먼저 저장하세요.

## AI 결과와 파일

- **AI 결과(JSON) 붙여넣기** 창에 JSON 배열을 붙여 넣고 **추가** 또는 **기존 핀 지우고 바꾸기**를 누릅니다.
- 작업 저장은 JSON 파일, 위험성평가표 CSV는 엑셀에서 열 수 있는 UTF-8 BOM 형식으로 저장합니다.
- Chrome·Edge에서 저장 위치를 묻는 창이 나오면 이 폴더 안의 `결과` 폴더를 선택하세요. 브라우저가 저장 창을 지원하지 않으면 다운로드 폴더에 저장되므로, 파일을 `결과` 폴더로 옮겨 보관하세요.
- 인쇄(게시용)는 A4 가로 방향으로 열리며 전체 파노라마 핀 위치와 위험성평가표를 인쇄합니다. 인쇄 설정에서 방향·용지를 바꿀 수 있습니다.

## 위험성평가 유의사항

- 위험도는 빈도(1~5) × 강도(1~4)로 계산합니다. 제시된 기준에서 7점과 11점은 구간이 정해져 있지 않아 `확인 필요`로 표시합니다.
- 사진에서 확인되는 사실과 추정 내용을 구분하고, 불확실한 내용은 현장에서 확인하세요.
- 법령 조항은 원문을 확인해 입력합니다. 앱이 자동으로 법령 적합성을 판단하지 않습니다.
- 위험성의 최종 판단과 결재는 안전관리자가 현장 확인 후 진행해야 합니다.

이 앱은 외부 서버로 내용을 전송하지 않습니다. 사진과 입력 자료는 이 브라우저 안에서 처리합니다.
